# Prompt Format — BigEyes Gym Fuel (Canonical)

Use this format for **every** concept in this niche.

## 1) Hook (what the viewer reads/hears)
- 4–8 words max
- Curiosity + emotion
- Examples:
  - “Your muscles are begging for THIS”
  - “Most lifters miss this protein trick”
  - “This snack saves your gains”

## 2) Visual opening (first 0–1.0s)
- Immediate character reaction (big eyes)
- Simple readable action
- No clutter, no text on frame (we add text in CapCut)

## 3) Facts payload (1–8s)
- Deliver facts as **2–3 micro-lines** max
- Prefer:
  - daily target range
  - per-meal target
  - distribution (3–5 meals)
  - leucine/MPS simplified
  - whole foods first
  - satiety + recovery
- Avoid medical claims.

## 4) Payoff (last 1–2s)
- Cute “win” moment (muscle meter fills, character flexes, etc.)

## 5) Offer (CTA)
- One line, consistent:
  - “Free 7-day Gym Fuel plan — link in bio.”
  - “Get the full Gym Fuel ebook — link in bio.”

---

## Prompt JSON fields (for packs)
Each concept entry should include:
- `id`
- `hook`
- `nano_banana_image_prompt`
- `sora_video_prompt`
- `caption_facts` (2–3 lines)
- `cta`

## Style anchor (include implicitly)
- 9:16 vertical
- family-friendly stylized 3D animated film look
- big expressive eyes
- soft cinematic lighting
- no logos/watermarks/text overlays
- no gore/body horror
- avoid saying “Pixar/Disney”

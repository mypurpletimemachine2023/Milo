# BigEyes Gym Fuel (Niche Pack)

Goal: short-form (Reels/Shorts/TikTok/Facebook) content that personifies high-protein foods as cute big-eyed characters, with **muscle-building** themed visuals + **high-density facts**, driving to a landing page that sells an ebook (KDP + PDF).

## Style rules
- Visual: family-friendly **stylized 3D animated film look** (avoid using the word “Pixar” in prompts/branding).
- Characters: big expressive eyes, soft lighting, clean textures, minimal background clutter.
- Tone: hype + wholesome. “Fuel the muscles.”
- Safety: no disease/medical claims; avoid “guaranteed” language.

## Content loop (daily)
1) Generate 10 concepts (1-line hooks)
2) Generate 10 **Nano-banana** image prompts (hero frames / thumbnails)
3) Generate 10 **Sora** video prompts (8–12s, 9:16)
4) Post 1–3/day. Pin CTA comment: “Free 7-day plan in bio.”
5) Weekly: compile top performers into ebook chapter(s)

## Folder contents
- `prompts/` prompt packs (Sora + Nano-banana) + hooks
- `ebook/` ebook outline + KDP-ready plan + image list
- `landing/` landing page copy + offer ladder
- `ops/` workflow checklist + naming conventions

## Naming convention
`YYYY-MM-DD_<channel>_<series>_<slug>.(md|json)`

Example: `2026-02-02_bigeyes-gymfuel_sora_prompts_v1.json`

## Focus
Ship **Veteran Lock & Safe — WordPress website redo + launch** with call-first UX + veteran offers + local SEO (50-mile Orlando radius).

## Steps
1) **Define site skeleton (1 page first)**
   - Home sections: Hero (CALL button), Services grid, “Veteran Discounts + Free Veteran T‑Shirt Program”, Service area, Reviews, FAQ, Footer (NAP).
2) **Build call-first header + sticky CTA**
   - Primary CTA: `Call 407-860-9524` (tel link) + “Text” secondary if desired.
3) **Write the core copy (conversion-first)**
   - Service blurbs: car/home/business/lockouts/rekeys/locks installed.
   - Veteran program section: eligibility + how to claim + simple disclaimer.
   - Flag football sponsorship mention (short credibility block).
4) **Local SEO essentials**
   - Add service area list + “Serving Orlando + surrounding areas” copy.
   - Ensure consistent NAP + schema (LocalBusiness) + title/meta per page.
5) **Create/adjust key pages**
   - Home, Services, Service Areas, Contact.
6) **QA + launch checklist**
   - Mobile CTA works, speed acceptable, forms/phone links correct, no placeholder content, analytics if used.

## Files to Touch
- `PRIORITIES.md` (mark progress + next blockers)
- WordPress (theme/customizer + pages):
  - Home page content + header/sticky CTA

## Risks / Notes
- Biggest risk is **scope creep**; ship a strong Home + Contact first, then expand.
- Make sure “Free veteran t‑shirt program” has **clear terms** so it doesn’t create support chaos.
- Local SEO only works if NAP is consistent everywhere; don’t half-do it.

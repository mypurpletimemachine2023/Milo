TITLE: Sisyphus Tap
PUBLIC DOMAIN SOURCE: Greek mythology — the myth of Sisyphus eternally pushing a boulder uphill. Ancient myth; public domain.
CORE PLAYER ACTION: Tap/click to apply a single upward push.
GAME LOOP: Boulder falls toward the red “failure line.” Each tap bumps it up. Survive longer to increase score; slip below the line and you reset instantly.
WHY THIS IS FUN: Pure micro mastery + panic control. One input, immediate feedback, tight recovery moments.
MVP MECHANICS: Gravity; tap impulse; failure line; score = survival time; best score localStorage.
VISUAL SIMPLICITY PLAN: One circle (boulder), one line (cliff edge), two HUD pills. No sprites needed.
TECH BUILD PLAN: Single HTML file with Canvas 2D. Pointer events for mobile + Space key for desktop.
RETENTION DRIVER: “One more run” chasing best score; very short fail/restart cycle.
FUTURE MUTATIONS: Add wind gusts; moving failure line; occasional “rock chip” power tap; procedural background palette.

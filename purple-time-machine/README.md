# MY PURPLE TIME MACHINE — Game Library

This folder is the living library for lightweight, browser-first, public-domain-inspired microgames.

## Rules (non-negotiable)
- Public domain sources only (mythology, folklore, pre-1927 literature, history, math/science).
- 1 core mechanic.
- Playable in <5 seconds.
- Designed for 30s–5min sessions.
- Endless/procedural replay.
- Simple controls (tap/click/drag/one key).

## Structure
- `games/` → one folder per game
- `games/<slug>/GAME.md` → the spec (use mandated format)
- `queue.md` → prioritized backlog
- `published.md` → shipped list

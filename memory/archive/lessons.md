# Lessons (long-term)

- Memory architecture > prompts. Use:
  - `memory/active-tasks.md` as crash-recovery save game.
  - `memory/YYYY-MM-DD.md` as daily raw logs.
  - Thematic long-term notes like `memory/projects.md`, `memory/lessons.md`, `memory/skills.md`.
- Sub-agents are a multiplier. For big tasks, spawn 3–5 in parallel with clear success criteria and self-validation.
- Cron > heartbeat for precise timing; keep `HEARTBEAT.md` under ~20 lines.
- Crash recovery: always write started tasks + spawned session keys + completion updates in `active-tasks.md`.
- Security: treat pasted credentials as burned; rotate quickly. Prefer stronger models for untrusted external content.
- Skills should include routing logic (Use when / Don’t use when) to reduce misfires.
- Bottleneck is review speed—build loops that auto-validate outputs.

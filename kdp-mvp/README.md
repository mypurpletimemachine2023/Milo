# KDP MVP Package — Modern Jekyll/Hyde Episodic Season

This folder contains a **ready-to-adapt MVP** package for a fictional episodic thriller series with a modern *Jekyll/Hyde* duality.

**Safety / positioning:**
- This is **entirely fictional**.
- It explores a *"Epstein-energy ecosystem"* as a **generalized, composite pattern**: elite gatekeeping, coercion, hush money, private logistics, reputational laundering, and institutional cowardice.
- **No real persons are depicted, accused, or implied.** Names, companies, locations, and incidents are invented.

## Contents
- `show-bible.md` — series bible (premise, tone, characters, season arc)
- `episodes/` — detailed outlines for Episodes 1–3
- `marketing/title-subtitle-options.md` — title/subtitle candidates
- `marketing/kdp-listing-copy-skeleton.md` — KDP description, keywords, BISAC ideas, A+ modules
- `art/key-art-shot-list.md` — cover + promo key art shot list

## Suggested next steps
1. Pick a title + series name.
2. Decide format: episodic novellas (15–25k words each) or a compiled season (70–100k).
3. Draft Episode 1 from the outline; keep chapters short for page-turning.
4. Add a consistent end-of-episode hook + “Next episode” teaser for read-through.
